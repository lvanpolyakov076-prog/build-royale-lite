# Build Royale Lite на российском хостинге

Один процесс Node.js обслуживает HTML и API лобби на одном адресе. Браузер получает графику и код игры из HTML. Отдельный CDN и база данных для запуска не нужны. Комнаты хранятся в памяти, поэтому запускайте один экземпляр сервера.

## Amvera Cloud

При создании приложения выберите регион «Москва» и загрузите файлы из распакованного архива. `Dockerfile` запускает Node.js на `0.0.0.0:8080`, а `amvera.yaml` направляет запросы на этот порт. После запуска добавьте технический HTTPS-домен в настройках проекта и проверьте `/healthz`. Приложение и сетевое лобби открываются с этого же домена.

[Настройки Docker в Amvera](https://docs.amvera.ru/applications/configuration/docker.html) · [Домены и маршрутизация](https://docs.amvera.ru/applications/configuration/network.html)

## Timeweb Cloud App Platform

1. В App Platform создайте приложение типа «Бэкенд», подключите [репозиторий игры](https://github.com/lvanpolyakov076-prog/build-royale-lite.git) по URL и выберите ветку `main`. Для публичного репозитория достаточно ссылки. Если разворачиваете архив с более новой версией игры, сначала обновите `index.html` и `server.cjs` в репозитории.
2. Выберите фреймворк «Другой», язык Node.js 22 и регион в России. Сверьте стоимость выбранной конфигурации в панели до запуска.
3. В расширенных настройках укажите команду сборки `npm run check`, команду запуска `npm start` и путь проверки `/healthz`. Папку проекта оставьте корневой.
4. Установите переменные `HOST=0.0.0.0` и `PORT=8080`. Если в панели задан порт источника для веб-сервера, укажите `8080` и для него.
5. После запуска возьмите технический HTTPS-адрес во вкладке «Дашборд». Откройте его без VPN и создайте новое лобби. Второй игрок открывает тот же адрес и входит по коду.

[Деплой бэкенда в App Platform](https://timeweb.cloud/docs/apps/deploying-backend-applications) · [Подключение Git по URL](https://timeweb.cloud/docs/apps/connecting-repositories)

## Российский VPS с Docker

Распакуйте этот архив на сервере и выполните из его папки следующие команды.

```sh
docker build -t build-royale-lite .
docker run -d --name build-royale-lite --restart unless-stopped -p 127.0.0.1:8080:8080 build-royale-lite
curl -fsS http://127.0.0.1:8080/healthz
```

Проверка должна вернуть `{"ok":true}`. Настройте HTTPS на обратном прокси и направьте запросы сайта целиком на `http://127.0.0.1:8080`, включая `/api/`. Для теста без Docker запустите `npm run check` и `npm start` в папке проекта с Node.js 22, затем откройте `http://127.0.0.1:8080/`.
